# Test BlogFlask

Test de l'aplicació  Proves Unitàries  i Proves d'integració
Utilitzem **pytest** que és un marc  de proves  amb python que executa  etsts automàtics. S'han de definir  les comprovacions  amb *asert*.

## Instal·lació

Instal·lar la llibreria pytest dins el nostre .venv

```bash
$ pip install pytest
```

# Execució dels tests
